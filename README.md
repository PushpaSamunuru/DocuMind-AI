# 📄 DocuMind AI

A privacy-first document intelligence platform.

## Features

- Chat with any text-based PDF
- Multi-document support
- Local AI (Ollama + Gemma 3)
- FAISS semantic search
- Evidence and citations
- Conversation memory
- Integrated PDF viewer

## Tech Stack

- Python
- Streamlit
- Ollama
- Gemma 3
- FAISS
- PyMuPDF
- Sentence Transformers
